Student Course Management System



* Problem Statement



Managing student records, course information, enrollments, and academic grades manually can be time-consuming and error-prone. A simple computerized system is required to organize these activities and provide quick access to academic records.



The Student Course Management System is a command-line Java application designed to manage student details, courses, course enrollments, grades, and basic academic reports.



* Scope



The project covers the following operations:



\- Student registration and management

\- Course creation and management

\- Student enrollment in courses

\- Grade assignment and evaluation

\- Student academic report generation

\- CSV-based data storage

\- Data backup



The system is designed as a console-based application and does not include a graphical user interface.



* Target Users



The primary target user is a college administrator or academic staff member who needs to manage student and course records.



* &#x20;High-Level Features



1\. Add, update, delete, search, and display students.

2\. Add, update, delete, search, and display courses.

3\. Enroll students in courses and prevent duplicate enrollments.

4\. Assign marks and automatically determine grades.

5\. Generate student academic reports.

6\. Store records using CSV files.

7\. Create backups of stored data.

8\. Handle invalid user input and common errors.
